# Goal

Replace the current tagline — "One number. One exact shuffle." — with a better one. The current line is agreed to be mid.

# Non-Goals

- Hero layout changes (owned by `2026-08-30-explorer-first-home.md`; this plan swaps words, not structure, and rebases onto whichever hero exists when it lands).

# Context

- The tagline appears as the hero eyebrow on `/`, opens talk mode's first slide, appears in page and social metadata, and is rendered into the static social-card artwork.
- Candidates to workshop, seeded from the design conversation:
  - "Every shuffle has an address."
  - "Your next shuffle is already here."
  - "All 80,658,… of them, in order." (full 68-digit count rendered by the site, not hard-coded)
  - "52! decks. One number each."
  - "Every possible deck, exactly numbered."
  - "52 cards. 80 unvigintillion possibilities." (42 chars — deliberately over the ≤ 40 guideline; 52! ≈ 80.66 × 10⁶⁶)
- Selection is by human review; this plan exists to track the exploration and keep both call sites in sync.
