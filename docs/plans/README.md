# Execution Plans

Execution plans are living implementation records for substantial work.

- Create plans in `active/` from `template.md`.
- Update tasks, decisions, deviations, and evidence while work proceeds.
- Keep exactly what happened, not only the original intention.
- Move fully verified plans to `completed/` **in the same PR that ships the work**, with the plan's status set to `completed` and its related commit hashes filled in.
- Preserve completed plans as project history; never delete them.

Plans describe how a decision is executed. Architecture decision records explain why a durable choice was made.
